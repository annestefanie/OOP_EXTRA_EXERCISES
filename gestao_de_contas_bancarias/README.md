## Simple Bank Account System (OOP in Java)

A basic project for practicing the fundamental concepts of Object-Oriented Programming (OOP) in Java, focusing on encapsulation, private attributes, and object state manipulation.

### Concepts Covered
- **Encapsulation**: `private` attributes with access control.
- **Constructors**: Initializing the default state of objects.
- **Business Methods**: Validating withdrawal and deposit operations.

### Project Structure
- `ContaBancaria.java`: Main class with attributes (`accountHolder`, `accountNumber`, `balance`) and methods (`deposit`, `withdraw`, `displayStatement`).
- `Main.java`: Test class to instantiate the account and simulate operations.
